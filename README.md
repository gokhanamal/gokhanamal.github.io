# gnamal.com

Source code for **https://gnamal.com**.

A minimal personal site + blog for **Gökhan Namal**.

## What’s inside

- Home, About, Beliefs
- Reading (Goodreads shelves via RSS)
- Bookmarks
- Apps (from Apple iTunes Search API)

## Tech stack

- **Astro** (based on **AstroPaper**)
- **Tailwind CSS**
- **GitHub Pages** (deploy via GitHub Actions)

## Local development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Content

- Blog posts live in: `src/data/blog/`
- Pages live in: `src/pages/`
